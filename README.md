# To-Do App

A simple and interactive React+ vite web application for managing daily to-do tasks. This project is built entirely on the frontend using modern React practices, including state management with hooks (such as `useState`), and dynamic list handling through filtering and mapping.

## Features

- Add and delete tasks
- Mark tasks as complete when we click task
- Filter tasks based on completion status
- Uses React functional components and hooks for state management
- Intuitive, user-friendly interface

## Tech Stack

- [React](https://reactjs.org/) (Functional Components)
- JavaScript (ES6+)
- CSS

## Getting Started

1. **Clone the repository:**

    ```bash
    git clone https://github.com/sanjaynep/to-do-app.git
    cd to-do-app
    ```

2. **Install dependencies:**

    ```bash
    npm install
    ```

3. **Start the development server:**

    ```bash
    cd todolist
    npm run dev
    ```

4. **Open in browser:**

    Visit releted local host
